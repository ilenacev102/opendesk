# ServiceDesk DESIGN.md — Enterprise ops console дизајн-систем

Насока: топол enterprise изглед — средно-силна челично-сина (не електрична),
неутрални површини со благи топли нијанси, семантички бои во soft-fill беџови.
Навигацијата е темна slate со ВИДЛИВО лого: акцент-плочка со бела икона + бел збор.

## 2. Компоненти

- **Navbar** (`.navbar-sd`): повисока (10px padding), солидна slate, без градиент;
  лого = акцент-плочка (10px радиус, сенка) со БЕЛА SVG икона + бел збор 1.15rem —
  секогаш видливо. Линкови со средна тежина, активниот е полна акцент-пилула.
  Search-поле е темно-транспарентно со светол текст; toggler секогаш видлив.
- **Копчиња**: примарно = длабок челичен акцент; секундарно = неутрално;
  danger = пригушено црвено, само за неповратни акции. Брзите акции се
  монохроматски икона-картички со slate икони (акцент само на hover).
- **Stat-картичка**: рамна, сив горен бордер, slate икона-chip; бројка во
  display-фонт. Боја само како исклучок со значење (жолт chip за „бара внимание").
- **Беџ** (`.badge-st`): soft-fill пилула — 10% нијанса на семантичката боја +
  заситен текст, без бордер. Мапирање: Available→ok, Assigned→info,
  Repair/Replacement→warn, Broken/Disposed/Lost/Stolen→bad, Repaired→teal.
- **Табела**: header со акцент-фон и бел uppercase текст (леплив), зебра преку
  Bootstrap, hover-подлога, секогаш во `.table-responsive` со `<thead>`.
- **Форма**: label 600/0.85rem над контролa; фокус = акцент-бордер + мек прстен;
  `:focus-visible` насекаде.
- **Пагинација** (`.sd-pagination`): пилули со радиус, активна = акцент.
- **Табови** (return): Bootstrap tabs, активен = акцент-текст + долна линија.
- **Empty-state**: SVG икона (`--sd-muted`), наслов + една реченица, без emoji.
- **Икони**: исклучиво SVG sprite (`templates_web/_icons.html`, `<use href="#i-*">`),
  24×24 stroke, `currentColor`. Emoji во UI е забранет (тест: `tests/test_ui.py`).
- **Анимации**: само `transform`/`opacity` (fadeUp, pageIn); почит кон
  `prefers-reduced-motion`.

## 3. Правила за темна тема

- Ниедна боја не се хардкодира во шаблон; сè преку токени.
- Chart.js боите се читаат од `data-bs-theme` при иницијализација + MutationObserver.
- Легендите и tooltip-овите наследуваат `--sd-text` / `--sd-muted`.

## 4. Што НЕ се прави

Без нови фонтови без причина, без градиент-текст, без анимација на layout
својства, без слабеење на UX заради поени, без `!important` надвор од print/utils.

## 5. Додатоци (фази Б–Г)

- **Потпис-pad** (`#sigPad`): max 460×150, Account dashed бордер, crosshair
  курсор; `.touch-none` го заклучува скролот на допир (инаку цртањето на
  телефон е скршено). Темна тема: темна подлога преку токен.
- **Warning-редови** (`.table-warning`): темна варијанта преку Bootstrap
  CSS-варијабли, жолт текст на темно-кафеава подлога.
- **Print**: крие nav/footer/копчиња/форми/alerts; картичките не се кршат
  (`break-inside: avoid`), сликите се печатат со точни бои
  (`print-color-adjust: exact`) — за QR-налепници.
